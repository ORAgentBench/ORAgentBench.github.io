ORAgentBench: Can LLM Agents Solve Challenging Operations Research Tasks End to End?

ORAgentBench evaluates autonomous agents on realistic operations research workflows: reading operational artifacts, building mathematical models, running solver code, and submitting auditable decisions checked by hidden validators.

Benchmark

Real OR work, not only formulation text

Each task packages a natural-language operational brief, multi-file data, configuration artifacts, and a required submission schema inside an isolated Harbor environment. Agents must produce executable solver code and decision artifacts that pass schema, feasibility, and normalized quality checks.

End-to-end workflow

Agents must reconcile public task files, design a model, implement a solver, run it from scratch, and preserve a validated submission under runtime limits.

Operational artifacts

Data is presented as realistic tables, calendars, compatibility matrices, scenario files, capacities, inventories, and route or schedule structures.

Hidden validation

Task validators score output schema validity, hard-constraint feasibility, and objective quality without exposing hidden evaluator logic to agents.

Difficulty by structure

Easy, medium, and hard tasks are controlled by modeling burden, constraint coupling, dynamic structure, data scale, and solving strategy requirements.

Evaluation protocol

Feasibility is necessary, quality is decisive

ORAgentBench reports feasibility, normalized quality, and pass rate. A task is passed only when the submission is feasible and its normalized quality exceeds the benchmark threshold. This exposes the feasibility-quality gap: agents may produce valid decisions that still fall short of robust OR practice.
