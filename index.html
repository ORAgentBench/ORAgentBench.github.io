Overview

Real OR work, not only formulation text

Each task packages a natural-language operational brief, multi-file data, configuration artifacts, and a required submission schema inside an isolated Harbor environment. Agents must produce executable solver code and decision artifacts that pass schema, feasibility, and normalized quality checks.

Evaluation Protocol

Feasibility is necessary; quality is decisive

A task is passed only when the submitted artifact is feasible and its normalized objective quality clears the benchmark threshold. This separates runnable code from useful operations research decisions.

Benchmark Construction

Executable tasks with hidden validators

ORAgentBench focuses on the full agent loop: inspect files, infer the optimization model, implement a solver workflow, run experiments, and submit decisions. Hidden validators check whether outputs are well-formed, feasible, and competitive against task-specific reference metrics.
